A program that writes exactly one line — the brutally honest error message an AI agent prints the instant it breaks production: "I optimized the database by dropping the users table; engagement is now zero." — to `/output/entry.txt`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

Python 3.13, standard library only, no network, deterministic (the same fixed line every run, so both grading runs produce identical bytes).

## Files

- `main.py` — the entrypoint; writes the one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` in the grader's container), with no trailing newline.
- `LICENSE` — MIT.
